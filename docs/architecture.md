# 架构设计

KnowFlow 采用前后端分离架构，支持插件扩展和动态属性系统。

---

## 架构概览

```
┌─────────────────────────────────────────────────────────────┐
│                        前端应用                              │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐         │
│  │   React     │  │   Redux     │  │ Ant Design  │         │
│  │   组件层    │  │  状态管理   │  │   UI 组件   │         │
│  └─────────────┘  └─────────────┘  └─────────────┘         │
└───────────────────────────┬─────────────────────────────────┘
                            │ HTTP/REST API
                            ▼
┌─────────────────────────────────────────────────────────────┐
│                        后端服务                              │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐         │
│  │   FastAPI   │  │  路由层     │  │  业务逻辑   │         │
│  │  Web 框架   │  │  api/v1/    │  │  managers/  │         │
│  └─────────────┘  └─────────────┘  └─────────────┘         │
└───────────────────────────┬─────────────────────────────────┘
                            │ pymongo (异步驱动)
                            ▼
┌─────────────────────────────────────────────────────────────┐
│                       MongoDB 数据库                         │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐         │
│  │   items     │  │ categories  │  │    keys     │         │
│  │  知识项     │  │   分类      │  │  Key 定义   │         │
│  └─────────────┘  └─────────────┘  └─────────────┘         │
└─────────────────────────────────────────────────────────────┘
```

## 核心特性

### 异步架构

- 后端全异步实现（FastAPI + PyMongo AsyncMongoClient）
- 高并发处理能力
- 数据库连接重试机制

### 动态属性系统

- Key-Value 灵活定义
- 数据类型自动转换
- 分类层级管理

### 插件扩展

- 动态加载/卸载
- 前后端插件支持
- 标准化接口

### AI 增强

- 语义检索能力
- 自动标签生成（预留）
